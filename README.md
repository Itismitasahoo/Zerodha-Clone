# Zerodha Clone

A full-stack Zerodha-inspired trading platform built with React, Node.js, Express and MongoDB.

## 🚀 Live Demo

[View Website](https://zerodha-frontend-vsm5.onrender.com) 
[View Dashboard](https://zerodha-dashboard-cq07.onrender.com)

## ✨ Features

- User registration and login
- Secure session-based authentication
- Trading dashboard
- Holdings and positions
- Portfolio visualization
- Responsive React frontend
- MongoDB database integration

## 🛠️ Tech Stack

Frontend: React, React Router, Bootstrap, Axios  
Dashboard: React, Chart.js  
Backend: Node.js, Express.js, Passport.js  
Database: MongoDB, Mongoose, MongoDB Atlas  
Deployment: Render
